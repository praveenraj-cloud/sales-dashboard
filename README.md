📊 Interactive Sales Analytics Dashboard

📌 Project Overview

This project showcases an interactive sales analytics dashboard built using Power BI.
It helps analyze business performance by tracking sales, customer activity, product trends, and regional distribution.

The dashboard is designed to provide clear insights through visualizations and key performance indicators (KPIs).

---

🎯 Objectives

- Analyze overall sales performance
- Identify top customers and products
- Compare regional sales distribution
- Track quantity and revenue trends
- Build an interactive and user-friendly dashboard

---

📊 Dashboard Features

🔹 KPI Metrics

- Total Sales
- Total Price
- Total Quantity
- Region Count

🔹 Visualizations

- Bar Chart → Product count by customer
- Horizontal Bar → Price distribution by quantity
- Pie Chart → Product distribution by region
- Donut Chart → Order analysis by Order ID
- Line Chart → Quantity trends
- Column Chart → Total sales by product

---

🛠 Tools & Technologies Used

- Power BI (Data Visualization)
- Microsoft Excel (Dataset)
- DAX (Data Analysis Expressions)

---

📂 Dataset Information

The dataset contains structured sales data including:

- Order ID
- Order Date
- Customer Name
- Region (North, South, East, West)
- Product & Category
- Price and Quantity
- Total Sales

📈 Key Insights

- Certain customers contribute significantly to product purchases
- Sales are unevenly distributed across regions
- Some products generate higher revenue consistently
